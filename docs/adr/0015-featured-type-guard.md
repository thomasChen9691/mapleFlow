# 0015 - 精选类型守卫：单模块收敛

**状态**：已批准（2026-10-26，项目负责人经 wayfinder 地图 `map-featured-type-guard` 工单 0073–0078 逐票 grill 定案）。基线：ADR-0009（精选机制——字段契约与首页行为）、ADR-0012（徽标三面与谓词同源）、ADR-0006（产品索引双 seam 与缺省纪律）、ADR-0008（分层判据）、ADR-0007（三层文档契约模式）、ADR-0014（docstring 契约定义处与自测模式先例）。过程记录存各工单 Resolution（决策进本 ADR、推理链留工单，两不混）。

## 背景

featured 的「非布尔即构建失败」执法原为三处逐字同构的拷贝：`layouts/partials/post-items.html`（文章，遍历全部文章）、`layouts/partials/product-items.html`（产品，与 kind 门禁合循环）、`content/posts/_content.gotmpl`（SOP 注册条目，条件传键）。谓词另有三形态（`where`×2 + 徽标 `eq`），坏值测试覆盖文章 2 例 + 产品 1 例、SOP 侧零。本图的目的地：把守卫收敛为单一模块，使该模块可测试、AI 可导航。事实底座见 `docs/wayfinder/research/0072-featured-guard-facts.md`。

## 决策

1. **职责边界 = 只做类型校验（0073）**：谓词判**契约**——三处谓词各有其主（post-items 无条件过滤属 ADR-0009 精选链、product-items 条件过滤属 ADR-0006 入参语义、徽标 `eq` 属 ADR-0012 主题层契约）；合并 = 为三种真实差异参数化（0061 枪毙的「搬家加参数化」）。模块只执法「featured 只认布尔 true；未声明合法；非 bool 即 errorf」，不提供谓词、不返回过滤结果。
2. **文档 seam = 双向互指（0073）**：模块 docstring 是 featured **执行契约的唯一定义处**（契约 + 消费面清单 + 徽标「语义共享、实现独立」声明）；三处消费方与徽标各留一句指针。这是 ADR-0012「谓词同源、契约各自独立」的落地形态，也是「AI 可导航」的落点。
3. **边界文本 = 校验器，不是选择器/取数器（0073）**：不拥有数据获取、选择语义（where/eq）、渲染呈现、消息前缀措辞；只回答「这个 featured 值合法吗」。
4. **测试口径 = 零增减零改写（0073）**：现有坏值断言原样存活（它们锚消费链「构建失败 + 消息子串」行为而非实现）；模块不新增专属断言（直接探针归 0077 裁）；SOP 缺口留 0077。验收 = 三套全绿 + 断言计数持平 + **变异等价**（破坏共享模块 → 坏值断言同时红）。
5. **接口 = 条目语义（0074）**：调用方传容器（`item`：Page.Params / 产品条目 / 注册条目），模块内 `isset` + `index` + 类型判定 + errorf——四件套全收敛；遍历留调用方（三处遍历模式本就不同）。
6. **入参 = 不自校验（0074）**：模块不验 item/origin/label，docstring 声明全必填。product-index 的自校验先例服务于内容作者输入（短代码属性，外部边界）；守卫参数是内部模板接口，防御性校验属为不存在的第四调用方写代码（投机泛化）。
7. **返回 = 无返回（0074）**：纯执法，不产出——合法静默过、非法 errorf 中止构建。返回 bool 即谓词化（与决策 1 矛盾）；返回值无真实消费方（YAGNI）。
8. **落点 = 站点层 `layouts/partials/featured-guard.html`（0075）**：ADR-0008 判据「因数据结构 / 契约而变 → 站点层」；三消费方全在站点层；徽标不消费 → 不引入 theme→site 新先例，主题层保持自洽（不持站点数据契约）。
9. **重开触发（0075）**：徽标谓词收敛或出现主题层消费方 → 重开分层决策；ADR-0012 的 theme→site 否决是**上下文特定的，不是永久禁令**。三要素（触发条件 / 重开对象 / 否定的上下文特定性）记在模块 docstring。
10. **消息形态 = 保留 origin 三前缀（0076）**：三前缀逐字（「文章精选数据：」「产品索引数据：」「SOP 发布管线：」）由调用方经 `origin` 传入——测试期望子串零改写、链身份（哪条链坏了）不丢；模块只持 errorf 骨架、不持措辞。
11. **label = 调用方格式化（0076）**：label 是**定位值**不是措辞（permalink / `%q` 引号 id / 「条目 %s」）；「条目」二字留在它所属的 SOP 链，不污染通用模块。
12. **命名与术语（0076）**：文件名 **`featured-guard.html`**（与 `featured-badge` / `post-items` 同族）；术语表**不新增**「守卫」词条（实现机制不是对外领域语言，ADR-0014 决策 9 先例）；`CONTEXT.md`「精选」条加一句 guard 指针（与 badge 指针并列）。
13. **测试缝 = 各消费链（0077）**：测公开行为（三条链的构建失败），**不建模块探针**——探针测 partial 内部 API（实现细节），改模块签名即误红；模块分支（未声明跳过 / bool 放行 / 非 bool errorf）经正路 + 坏值 fixture 全触达。
14. **SOP 坏值缺口 = 补（0077）**：`tests/fixtures/bad/sop/sop-featured-not-bool/`（`featured: "true"` 字符串）+ `BAD_CASE_EXPECT` 登记（钉 origin + label + 契约三要素，防「因别的原因失败也绿灯」）；SOP 套件 104→105。坏值断言共四条：文章 string/int + 产品 string + SOP string。
15. **自测模式 = 不适用（0077，已知差异）**：Hugo 模板侧无可独立执行的 seam（不像 harness 的 Node/Python 文件），ADR-0014 决策 8「自测先于契约红」的定位优势不存在；模板侧模块的可测试性由套件级消费链断言承担。

## Considered Options

- **谓词合一 / 整批语义**（决策 1 / 5，拒绝）：谓词三形态各有其主，合并是为真实差异参数化；整批语义要把「与 kind 门禁合循环」「与五类检查合循环」参数化——0061 判例枪毙。
- **值语义**（决策 5，拒绝）：只收敛四件套中的三件，`isset` 与「未声明合法」的判定权分散到三个调用方，未来新增消费方仍要自己写。
- **自校验**（决策 6，拒绝）：内部模板接口、三处字面量；校验分支需要配套断言，而探针已被决策 13 否掉。
- **返回 bool / 返回值**（决策 7，拒绝）：前者谓词化（与决策 1 冲突），后者无消费方。
- **主题层落点**（决策 8，拒绝）：数据契约下沉到呈现层，方向反了；ADR-0008 判据指向站点层。
- **统一前缀 / 纯统一前缀**（决策 10，拒绝）：三套件期望子串全改、消息变长；链身份丢失让构建日志难定位。
- **模块按形态格式化 label / 统一 label 形态**（决策 11，拒绝）：前者让模块持有调用方措辞（「条目」属 SOP），后者改写全部消息。
- **改名 `featured-type-guard.html`**（决策 12，拒绝）：精确度提升有限，代价是 3 调用点 + docstring + AGENTS.md + fixture 复制清单全改。
- **模块探针 / 探针 + 链断言双保险**（决策 13，拒绝）：测内部接口、改签名误红；与链断言对同一 bug 双盲（ADR-0010 先例的已知限制）。
- **不补 SOP 缺口**（决策 14，拒绝）：单模块唯一未被证明接上的调用方，留正向证据不足。
- **自测模式适用（建探针当自测）**（决策 15，拒绝）：探针与其余断言同属一个套件，无「先于」的定位优势，且与决策 13 矛盾。
- **只加 ADR-0009 指针 / 只新开 ADR**（0078，拒绝）：前者让 15 条决策散落工单、违反 ADR-0004；后者让旧 ADR 的过期文件归属无指针可循。

## Consequences

- **改精选类型契约 = 改 `layouts/partials/featured-guard.html`**（契约 docstring 即定义处）+ 三处调用点（`post-items.html` / `product-items.html` / `_content.gotmpl`）+ 徽标谓词语义核对（`featured-badge.html`，语义共享、实现独立）。
- **导航**：`AGENTS.md` §7 速查表新增守卫模块行、坑点 9/11 的归属改指守卫；`CONTEXT.md`「精选」条留 guard 指针；三处消费方 docstring 留一句指针。
- **测试**：四条坏值断言（文章 string/int、产品 string、SOP string）+ 正路 fixture 覆盖 unset/true/false；变异口径 = 禁用模块类型检查 → 四条同时红（site 156/159 + sop 104/105）。
- **已知限制（诚实入档）**：① 无模块专属探针（决策 13）；② ADR-0014 自测模式不适用（决策 15）；③ 入参不自校验（决策 6）——第四调用方缺参只会在坏值路径表现为消息畸形。
- **施工记录**：`a1202e8`（图 + 0072/0073 + 围栏修复）、`c8725e8`（模块 + 三处迁移 + 四处指针 + AGENTS 同步）、`7a01618`（0074–0077 Resolution + 地图）、`2cf3d2a`（SOP 缺口 + docstring/术语同步）。分支 `refactor/featured-guard-module` 基于 `refactor/harness-convergence` 尖（自 main 起 13 笔，含基点可视批 4 笔），**全部未推**（GitHub auth-required）——笔数以 `git log` 为准；收口 handoff 见 `docs/handoffs/2026-10-26-featured-guard-closure.md`。
