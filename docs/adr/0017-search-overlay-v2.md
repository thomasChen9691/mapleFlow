# 0017 - 搜索浮层 v2：可测试性、AI 可导航与契约深化

**状态**：已批准（2026-11-15，项目负责人经 wayfinder 地图 `map-search-overlay-v2` 工单 0089–0094 逐票 grill 定案）。基线：ADR-0002（no-js 基线）、0007（docstring 契约定义处）、0008（分层判据）、0010（搜索契约 / 六字段冻结 / 不重写）、0011（搜索入口 / 所有权分层）、0013（搜索浮层 v1）、0014（harness / 无第四套 config）、0016（注册缝 / parity 门）。推理链留各工单 Resolution，本文件只承载决策；施工记录见 `docs/handoffs/2026-11-15-search-overlay-v2-construction.md`。

## 背景

ADR-0013 落地浮层 v1 后留下四处未消化面：① 两条「v1 不做」（方向键 / 命中高亮）只有一句 Consequences、无重开触发条件；② 候选 12 收口时挂起的三条雾区（移动端 / aria / 浮层空间关系），其触发条件「将来出现浮层形态」已被 ADR-0013 自己兑现；③ 浮层引擎 docstring 与 `assert_search.mjs` 测试头写返回 `{ open, close, isOpen }`，实现只返回 `{ open, close }`，零消费零断言；④ 浮层有可见错误态并引导去 search 页，而该页 fastsearch 的 XHR / `JSON.parse` 仍静默失效。工单 0089 的事实底座另盘出 13 条缺口。

目的地：把架构从现状深化到搜索浮层 v2，使该模块**可测试、AI 可导航**。**本图只产决策**，施工经项目负责人指示后另开两笔提交。

## 决策

### A. 可测试性的判据与测试缝（工单 0090）

1. **分层判据**（0090）：「可测试」按所有权分层验收——① 站点层浮层引擎：docstring 每条契约条款都要有**可定位地红**的断言；② 主题层 DOM 骨架：只走产物断言；③ legacy fastsearch：维持弱断言 + 记录在案的一次性验证。把 ADR-0011 决策 4 的所有权分层从两类扩到三类。
2. **不新增第四套 config、parity 边界不变**（0090）：沿用 ADR-0011 决策 4 / ADR-0013 决策 9；ADR-0016 决策 17 与 0086 决议的「`aria-*` / `inert` / `hidden` 不进反向」维持。一次性验证不升级为常驻断言。
3. **返回形状消解**（0090 补问）：`isOpen` 零消费方 → **删 docstring 与测试头里的该键、对齐实现 `{ open, close }`，并补一条返回形状断言**；不补实现、不新增公开 API（ADR-0015 决策 6 投机泛化判据）。

### B. 键盘与呈现（工单 0091）

4. **只补方向键**（0091）：ArrowUp/Down 选择结果，选中态契约（li `id` / `role=option` / `aria-selected`、input `aria-activedescendant`、ul `role=listbox`）归 `mf-search-overlay-engine.js` 头 docstring，配常驻 jsdom 断言；**MFO-15「Enter 首条」原样存活**。
5. **命中高亮不做**（0091）：维持 ADR-0013 的 v1 不做，作为**负向边界耐久化**；理由沿用 ADR-0011 决策 2（需消费 fuse matches、违背只改渲染层）。**重开触发条件** = 结果可读性成为真实且高强度需求，且须先按 AGENTS §8.2 提重审。fuse parity 四元组不动；浮层与 search 页键盘行为允许不同，边界写进 docstring，避免被当漏实现补上。

### C. a11y 与移动端（工单 0092）

6. **三条挂起雾区分别毕业**（0092）：① 触屏入口判**已兑现**（复用 `.mf-search-link`，只补断言、不新立触发面）；② aria 契约**扩写**进引擎 docstring——`aria-expanded` 由引擎在 open/close 时写到触发器节点（触发器在主题层，但不新增主题层脚本，避免破 ADR-0008 分层判据），`aria-activedescendant` / `aria-selected` 与方向键联动；③ 小屏首屏空间关系判**视觉层 Out of scope**，不重开地图边界。
7. **选中态用属性选择器**（0092 实施细化）：视觉反馈走 `.mf-search-item[aria-selected="true"]`，**不新增 `is-*` class**——否则 ADR-0016 的 RGR-14 正向（JS 写的状态 token 必须有 CSS 消费）会红。

### D. 容错与文案（工单 0093）

8. **不统一两个加载面的容错语义**（0093）：浮层可见错误态 / search 页静默失效的**不对称是有意设计**，给 ADR-0010 / 0013 加指针行写明「勿当漏实现补上」；fastsearch 一字不改（ADR-0013 决策 1），不重开 ADR-0010 决策 5，不回头修订本 ADR 决策 1。**重开触发条件** = 真被 XHR 静默失败咬到，或结果可读性成为真实需求。
9. **浮层侧细化**（0093 补问）：**不自动重试、失败不写缓存**（缓存只存成功结果；关闭重开自然再拉，不写进契约）；`indexUrl` 缺失沿用返回 `null` + MFO-2 降级；错误文案删「或前往搜索页」改为「索引加载失败，请稍后重试。」，**继续硬编码中文、不进 i18n**（单语言站、骨架已有硬编码先例）。

### E. 收口与导航（工单 0094）

10. **一份 ADR-0017**（0094）：一图一 ADR、各条注工单号（ADR-0015 / 0016 先例），不按面拆多份。
11. **指针三笔、术语与导航**（0094）：0010 / 0011 / 0013 各加一行指针（正文不改）；`CONTEXT.md` 只扩写既有「搜索浮层」词条、不新增实现机制词（ADR-0015 决策 12）；`AGENTS.md` §7 增行 + 坑点 14 / 18 补注；`docs/README.md` 计数归清理批、不顺手改。
12. **决策完备即闭图**（0094 补问）：frontier 空 + 六票 Resolution 落档 + 地图 Decisions so far 六行 = 地图 closed；**ADR / 指针 / CONTEXT / AGENTS / handoff 的落档属收口批施工，不进闭图条件**（`map-search-entry` 先例）。本图始终不含施工。
13. **施工序列与回滚点**（0094 补问）：**两笔提交**——① 契约与实现笔（docstring / 实现 / 断言 / 骨架文案与 aria / CSS 功能性反馈），回滚点 = 整笔（docstring 与断言同进同退，不许只回退一半）；② 文档资产笔（本 ADR + 指针 + 术语 + 导航 + handoff），可独立回退。每笔各跑四道门。

## Considered Options

- **统一条款级判据**（0090，拒绝）：会推动 fastsearch 重写、触发 ADR-0010 决策 5 重评。
- **最小判据**（0090，拒绝）：会留返回形状零断言的洞。
- **两条都补 / 两条都不补**（0091，拒绝）：前者要重开 ADR-0011 决策 2 负向；后者丢掉已 materialize 的触发条件。
- **统一到都有可见错误态 / 整体外推**（0093，拒绝）：前者与决策 1 分层判据冲突并需重评；后者忽略「触发条件已出现」。
- **按面拆多份 ADR / 不新开 ADR**（0094，拒绝）：前者导航面变大、与一图一 ADR 先例相悖；后者决策集无独立耐久化。
- **等 ADR 落档才闭图 / 重绘边界纳入施工**（0094，拒绝）：前者与「不含施工」冲突；后者拉长周期。

## Consequences

- 改契约 = 改 `assets/js/mf-search-overlay-engine.js` 头 docstring + 同步 `tests/assert_search.mjs`（MFO-1..28）与 `tests/assert_site_contracts.py` 产物断言；新断言须以变异检验证牙。
- 断言计数：`npm test` 41 → 50（新增 MFO-20..28 九条），站点契约 185 → 188（错误文案 / listbox / 契约文本不再声明多余返回键）；harness 19、SOP 105 不变。
- 施工第 1 笔 `0326bcd`（契约与实现，CI run `43723746836` 双 job 全绿、gh-pages `c20809d` 已部署）；第 2 笔为本 ADR 与导航资产（纯文档）。
- **已知限制（诚实入档）**：① 命中高亮不做、浮层与 search 页键盘行为不一致（负向边界，重开触发见决策 5）；② 两面容错不对称（负向边界，重开触发见决策 8）；③ 一次性验证未升级为常驻断言；④ parity 只守存在性不守语义漂移（ADR-0016 决策 20）；⑤ 三条挂起雾区随 closed 地图保存，勿从闭图直接复工单。
