# 0016 - 架构深化：文章卡片单模块、注册缝、死面、CSS 影子契约

**状态**：已批准（2026-10-27 至 10-31，项目负责人经 wayfinder 地图 `map-architecture-deepening` 工单 0080–0088 逐票 grill 定案并施工）。基线：ADR-0002（no-js 基线）、ADR-0007（reveal 协议：DOM 契约定义处=引擎 docstring）、ADR-0008（分层判据）、ADR-0009/0012（精选链与徽标）、ADR-0015（决策记录粒度：一图一 ADR、决策各注工单号）。推理链留工单 Resolution，本文件只承载决策。

## 背景

架构评审（2026-10-25）留下四条候选（③ 文章卡片单模块 / ④ 注册缝下沉 / ⑤ 配置·CSS 死面 / ⑥ CSS 影子契约 parity），前图 `map-featured-type-guard` 曾把它们记为「各自独立目的地」。本次经项目负责人决定**合并为一个目的地**：四条共享同一批文件与同一套断言，分图会让同一处代码被四张图反复触碰。

起点事实：卡片 markup 在 `layouts/index.html` 与主题 `_default/list.html` 各写一份且已语义发散（首页卡无 cover / 无草稿标记 / 无 `hideMeta` 守卫）；三引擎在模块尾部各自 `autoInit()`、import 即副作用；`archive.css` / `profile-mode.css` 零引用；JS 写的 `is-in` / `--mf-progress` 等与 CSS 消费侧靠人肉同步。

## 决策

### A. 文章卡片单模块（工单 0080–0082）

1. **一套类名、视觉零 diff**（0080）：卡片只输出一个类名；依据是两套 CSS 本就成对等价（`custom.css` 有 9 组 `.post-entry, .mf-post` 双写）。类名统一后为保住首页原样，主题卡的 `margin-bottom` 在首页容器内清零。
2. **三面同卡、`first-entry` 删除**（0080）：首页网格 / section 列表 / term 列表共用同一 partial；`first-entry` 与 `tag-entry` 分支**不可达**（首页走 `layouts/index.html`，`list.html` 的 `$.IsHome` 永不成立），一并删除。
3. **三处差异不参数化，统一「总是执行、条件自守」**（0080）：cover 恒调（空则不出）、草稿标记恒判、`hideMeta` 恒守。依据：三处差异在生产路径**全不可观测**（全站无 cover、草稿不进生产构建、无人设 `hideMeta`）；为不存在的输入参数化属投机泛化（同 ADR-0015 决策 6 判据）。草稿分支因此不测，记为已知限制。
4. **落主题层、零参数**（0081）：`themes/maplemod/layouts/partials/post-card.html`，只收一个 Page。判据 ADR-0008（视觉骨架→主题层）；两个消费方都能调（site→theme 有先例）；内部三个 partial（cover / featured-badge / post_meta）同层自洽。**未选站点层，故不重开 ADR-0012 的 theme→site 否决**。
5. **父容器契约载重**（0081）：卡片不自带布局，必须是网格容器的**直接子元素**；`:has()` 一律用直接子选择器（`main:has(> .post-card)` / `.mf-posts:has(> .post-card)`）。历史实现靠「两个不同类名」当面的判别器（`custom.css` 旧注释写着「类名不同，不会命中这里」），类名统一后该判别器消失，改由 DOM 位置承担——退回后代选择器会让首页 main 被误变网格。
6. **测试缝 = 结构 + 跨面等价 + 变异**（0082）：新增 `assert_post_card`（site 套件第十六类）与 `tests/fixtures/content-card/`；断言钉四段骨架、单一类名、父容器深度、类名↔产物 CSS 落地牙；**跨面等价（同一篇在首页与列表渲染出同一骨架）是「单模块」唯一的直接证据**；五条变异各自可定位地红。

### B. 注册缝（工单 0083–0084）

7. **对齐搜索入口的装配式**（0083）：引擎删除 import 期 `autoInit`，`app.js` 成为唯一挂载点（`ENGINES` 表 + 显式调用）。这不是新形态——`mf-search-overlay.js` 早就是「引擎纯导出 + 入口装配」，只有 reveal 是自注册的异类。
8. **挂点发现权归引擎、注册点唯一**（0083）：选择器（`.reveal` / `.mf-index` / `.mf-progress`）与契约 docstring 同文件（ADR-0007「契约定义处唯一」）；`app.js` 只调用、不持有选择器。`filter` 的单元收元素，故其挂载入口为 `mountFilter(doc)` 而非 `initX(doc)`。
9. **顺序无关 + 逐个隔离**（0083）：三引擎互不依赖，数组顺序不是契约；每个挂载各自 `try/catch` + `console.error`，单个失败不连带其余。理由 ADR-0002：`scroll-in` 不跑时 `.reveal` 停在 `opacity:0`（内容消失），不能让一个筛选 bug 把阅读进度条一起带走。
10. **`scroll-in` 自身 fail-open**（0084）：引擎内部 try/catch，异常走与「无 IntersectionObserver」同一条降级路径（全量直写 `is-in`）。隔离只保其余引擎，保不住「自己炸了内容还在」——这条兜底必须留在拥有 DOM 契约的引擎里。
11. **测试加载面 = `loadMounted` + 装配完整性**（0084）：`dom.mjs` 提供「加载 + 挂载」一次完成；`RGR-13` 用**行为面**验装配（装三类挂点、载生产入口 `app.js`、验点亮/计数/进度三个副作用），而非源码扫描——`import './x.js'` 也会命中，扫描式检查对「漏进 ENGINES 表」是假绿。

### C. 死面（工单 0085）

12. **判据 = 四面零引用 + 三类白名单**（0085）：类名/变量在 markup + JS + data + i18n 四处均无字面出现即为死。白名单登记三类假阳性：构建期生成（chroma token、highlight 行号表）、运行时拼接、渲染器产出。
13. **配置侧：零读取点与注释遗留键删、值恒等默认保留**（0085）：`[[params.socialIcons]]` 全仓零读取点即删；注释掉的 PaperMod 遗留键按 AGENTS 坑点 3「不留文档价值」删；`defaultTheme = "auto"` 这类有读取点但值等于默认的**保留**（活配置的显式声明）。
14. **粒度 = 文件 + 选择器块；不加死面守门**（0085）：整文件删（装配是通配，删文件自动不并入）+ 选择器块删；删块必须连带查 `var(--x)` 引用链（只被死块引用则一并删）。**不加守门断言**——死面判定是启发式，守门会误红且白名单要长期维护。
15. **删除笔零断言改动**（0085 实施细化）：删除那一笔跑完必须套件原样全绿，断言文件一个字符都不改——动了断言即说明删到了活的东西，回退重判。

### D. CSS 影子契约 parity（工单 0086–0087）

16. **清单 = 源码双向抽取，不手写 registry**（0086）：手写清单会变成第二个契约定义处（与 ADR-0007 冲突）且改 JS 忘改清单就假绿；docstring 仍是唯一定义处。
17. **反向范围收窄到 `is-*` 状态词表、白名单为空**（0086 实施细化）：正向 = JS 写的 class/变量必须有 CSS 消费；反向 = CSS 消费的 `is-*` 必须有生产者（JS 写 或 模板 class 属性）。`mf-*` 视觉类不进反向——否则反向检查就变成死面守门，与决策 14 冲突。
18. **抽取器独立、只懂词法、带定位**（0086/0087）：`tests/tokens.mjs` 出 `{writes, reads, markup}` 三张表，每 token 带 `file:line`；不持白名单、不判方向、不懂 `is-*` 范围（那是断言层的事）。机制可被 `assert_harness` 独立自测（ADR-0014 决策 8 的先例）。
19. **落点 `assert_reveal.mjs`、强度 = 测试红、消息带四处定位**（0087）：CI 门禁已把「测试红」等同「合不进去」，构建期 `errorf` 的额外收益抵不上在模板里正则解析 JS 的成本。消息分两向：正向报「被谁写入、无 CSS 消费」，反向报「被谁消费、无生产者」。
20. **已知限制：只守存在性，不守语义漂移**（0086）：同名不同义（JS 只在 reduce 时加、CSS 当常态样式）发现不了，语义仍靠 docstring 与 review。

## Considered Options

- **两套类名保留、模板只合并**（决策 1，拒绝）：DOM 契约仍是两套，parity 与死面清单永远有例外。
- **统一到 `post-entry` 族**（决策 1，拒绝）：`mf-*` 是站点品牌层的既有词汇，且 `post-entry` 族里带着不可达的 `first-entry` / `tag-entry`。
- **完整配置矩阵（cover/draft/meta/class 四开关）**（决策 3，拒绝）：每个开关当前都不可观测，partial 会变成配置矩阵。
- **站点层落点**（决策 4，拒绝）：主题层 `list.html` 必须调它 → 破 theme→site 零先例，且 ADR-0008 禁止靠同路径覆盖绕开。
- **保留 `autoInit` 作为测试出口**（决策 7，拒绝）：同一引擎两条注册路径，与「注册点唯一」直接矛盾。
- **不隔离、错就整包死**（决策 9，拒绝）：线上一个引擎 bug 会让 `.reveal` 内容永远不可见。
- **反向守全部 CSS 类**（决策 17，拒绝）：等于把死面守门补上（与决策 14 冲突），且 chroma/highlight 要长期白名单。
- **反向扫构建产物 HTML**（决策 17，拒绝）：零白名单，但落点要挪到 site 套件、门依赖一次 Hugo 构建（重开决策 19）。
- **手写 token registry**（决策 16，拒绝）：第二个契约定义处 + 必然漂移。
- **构建期 errorf 做 parity**（决策 19，拒绝）：模板里 `os.ReadFile` + `findRE` 解析 JS，不可维护。
- **死面守门断言**（决策 14，拒绝）：启发式判定会误红，白名单需长期维护；防回流靠 review + parity 门覆盖 token 面。

## Consequences

- **改卡片契约 = 改 `post-card.html` 的 docstring**（DOM 契约与父容器契约定义处）+ `assert_post_card`；改类名 = 同时改 `CARD_CLASS` 常量与 CSS（断言会红）。
- **加 reveal 引擎 = 建文件 + 在 `app.js` 的 `ENGINES` 表加一行**；`RGR-13` 会验装配，`RGR-14` 会验新 token 有没有 CSS 消费。
- **改 JS 写的状态 token = 同步 CSS**；否则 `RGR-14b` 红并指出写入点。CSS 删掉某 `is-*` 消费会同时触发反向检查。
- **导航**：`AGENTS.md` 坑点 10 增注册缝纪律、坑点 12 之外新增死面/token 两条；`CONTEXT.md` 新增「文章卡片」词条；ADR-0007 / 0008 各加一行指针（正文不改）。
- **测试计数**：site 159 → 185（卡片 22 + 解析前置 4）；npm 8+23+41 → 13+31+41；sop 105 不变。
- **已知限制（诚实入档）**：草稿卡片分支不测（生产不可达）；parity 只守存在性不守语义；死面无长期门；卡片视觉零 diff 未做像素级验证。
- **施工记录**：PR① = `31117d5`（文档）+ `34e068b`（卡片 + 注册缝）；PR② = `8e7b785`（死面删除，−196 行、零断言改动）+ `08f1280`（parity 门，含 `tokens.mjs` 与 RGR-14）。
