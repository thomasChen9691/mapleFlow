## Resolution

2026-10-22 · grilling（用户为决策者），三问 + 先例落定：

1. **术语一词条两指针**：「搜索索引」条内含投影与检索两个定义处指针（0046 施工期已落）；**不新立「搜索协议」术语**——快照契约的定性是「vendored 现状记录、非设计目标」，立同级概念名等于把现状升格为设计；重写发生时新引擎配新词。0046 决议①「并列互指」表述按实际落法勘误。
2. **单份 ADR-0010 五组决策**：模块边界与 seam 形状（0043）/ 字段契约（0044）/ kind 门禁（0045）/ 协议归属（0046）/ 测试缝（0047）。指针行三处：0006（0019 边界定案：索引零暴露、隐式兜底）、0007（搜索 JS 归属闭环：独立快照契约）、0009（索引不投影 featured）。三份正文不改（ADR 是历史记录）。
3. **AGENTS.md**：§7 加两行（`layouts/_default/index.json` 投影契约 / `themes/maplemod/assets/js/fastsearch.js` 搜索协议，各带「契约定义处」标注与测试指引）；坑点加第 13 条「搜索契约纪律」（字段集冻结 / 改 keys 三处同步 / 禁项目级覆盖复活）；§3 命令不动。
4. **收口节奏**（候选 7 先例，非新决策）：同场施工 → handoff（`docs/handoffs/2026-10-22-candidate-8-closure.md`）→ 地图 closed；push 与 CI 验证由项目负责人指示。

**雾区终局**：四条雾区（结果呈现层深化 / 引擎形态 / 容错 UX / 入口形态）全部移入 Out of scope——均挂在「重写 fastsearch」或「新功能」上，而目的地是现状治理（「从现状深化，不替换搜索实现」）；重写若发生，是下一张图的事。
