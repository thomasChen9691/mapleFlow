2026-10-23 · grilling（HITL，用户为决策者；五问落定，全部记录经用户逐条确认共识）。**本题关闭 = 本图目的地到达（决策面）**——收口批施工待项目负责人指示展开。答案五条：

2. **指针三笔**（先前 ADR 正文不改）：**ADR-0010 两笔**——重评结论回留痕（其 2026-10-23 指针所列「第二个消费方」触发条件已被本图正式评估、结论不触发）+ 快照扩写说明（li 条款加摘要，位置与工单）；**ADR-0007 一笔**——搜索入口交互归 reveal 与否的边界闭合（否：纯功能交互、零动效面）；**ADR-0008 轻笔**——站点层交互引擎实践已有两例（reveal、搜索入口），判据（交互→主题层）与实践第二次偏离，备注而不改判据。
3. **术语**：CONTEXT.md 新条「搜索入口」（放「站内搜索」节、「搜索索引」条之前——先路由后索引的阅读顺序）：全站 `/` 快捷键把任意页面路由到搜索页、只负责跳转/聚焦、检索仍归搜索索引链路；契约定义处 = `assets/js/mf-search-entry-engine.js` 文件头 docstring（与 fastsearch.js docstring 并列互指不合并）；_Avoid_: 搜索框、搜索按钮、命令面板。「搜索索引」条轻触：检索交互契约括注补「摘要渲染」一词。
4. **AGENTS.md 三笔**：§3 `npm test` 注释改双套件描述；§7 速查表加一行（入口引擎 + 入口文件，站点层）；**坑点 14「搜索入口纪律」**四条——两个搜索 JS 面加载条件不同（fastsearch 仅 search 页 / 入口全站恒加载，勿混勿并）、`js.Build` params 是 ESM import（`@params`）不是全局（旧 fastsearch 裸 `params` 是死路径）、入口只路由、第二个消费方由加载面双向断言守门、测试所有权分层。
