## Question

状态推导收敛后，首页数据条「N 份可下载产品」按术语表口径为 0（5 条全是占位）。这一格怎么呈现？候选：

- (a) 显示 0 —— 诚实优先，数字即事实；
- (b) 改显产品总数（「N 个产品」，不带可下载承诺）；
- (c) 暂时隐藏该格，等真实上架后恢复。

参考：用户曾因可转债溢价率展示存在误导风险而拒绝上线该指标 —— 诚实呈现是强偏好；但「显示 0」与「隐藏」的读者感受不同，需要拍板。

## Resolution

2026-10-15 · grilling（用户为决策者），一问落定：

**(a) 显示 0**——指标含义不变，数字即事实。核心理由：指标的含义不因数字大小而重定义（与用户拒绝可转债溢价率指标的同一纪律）；真实上架后数字自动长成真话，无需二次改标签。(b) 的「站点规模体裁」论证被审视后否决：这一格的原始承诺从来是「可拿」，错位是设计遗产而非本工单要重定义的对象；(c) 否决：「暂时」从来不会自动结束，且损失信息。

**执行期含义**：`index.html` 数据条该格的计数改为消费模块的「已上架」判定（不再是 `where site.Data.products "buy_url" "!=""`），迁移后当前值为 0，属预期而非缺陷。
