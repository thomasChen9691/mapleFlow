## Resolution

2026-10-22 · grilling（HITL，用户为决策者；三问全决）：

**前提修正**：本题原写于「本图只产决策」假设之上；施工已按项目负责人指示同场完成（`eec689f`），故原第 2/3/5 问的大部分在施工期已落地——`CONTEXT.md`「精选」与「注册表」条已改、`AGENTS.md` §7 `post-items.html` 行 / §3 命令与旧名指针 / 坑点 8 与 9 已更新。本题只决剩余三项：

1. **耐久化 = 新开 ADR-0009**（0020/0026/0034 同款），承载候选 7 五组决策（字段契约 / 首页行为 / seam 形状 / 测试缝 / 派生文归属）；**ADR-0006 加指针行**——其 featured 语义已被「跨类统一」扩展（非布尔即 errorf）；**ADR-0005 的指针已在施工期以补记形式落**（契约四类 → 五类），本题确认不加第二处。
2. **导航 = 新增坑点 11「文章精选纪律」**：数据准备只此一处、补集必须对**实际显示的精选**求、featured 只认布尔、两块空集即整块不渲染；附测试坑一条（Hugo 默认不发布未来日期的内容，fixture 写未来日期会假绿）。`themes/maplemod/README.md` 不提（首页编排属站点层，与判据一致）。
3. **收口 = 同场做完**：本场写 ADR-0009 + 坑点 11 + `docs/handoffs/` 交接，地图标记 closed（0034 先例）。

**术语终态**：不新增「精选池」类术语（0034 先例：术语表只收有独立决策的概念）；「精选」条已在施工期补齐「缺省即非精选 / 只认布尔 / 互斥与回落」语义，不再改。
