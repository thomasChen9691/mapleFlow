## Question

「featured 类型守卫单模块」的职责边界——模块管什么、不管什么。三处拷贝中一模一样的是「`isset` + 非 bool → `errorf`」（守卫）；谓词（只认 `true` 的选择语义）有三种形态且分散在三个文件。候选边界：

- **(a) 只做类型校验**——谓词各留原味（`where` / `eq` 是 Hugo 内建惯用法，本身无坏值风险）；
- **(b) 守卫 + 谓词合一**——模块同时提供「校验」与「是否精选」判定，两处 `where` 与徽标 `eq` 都改为经模块；
- **(c) 守卫 + 谓词 + 过滤全合一**——模块直接产出精选 slice（替代 `where` 调用）。

要决策的面：

1. **边界选 a / b / c 哪个**。判据用 0061 所有权测试——谓词是「机制」（应只有一个所有者）还是「契约」（各有其主：post-items 的页面集合过滤 / product-items 的条件过滤 / 徽标的渲染判定，三者数据形态与消费意图不同）。
2. **徽标谓词（主题层 `featured-badge.html` 的 `eq .Params.featured true`）是否收敛进模块**——其 docstring 自称与守卫「同源」，「同源」是否必须「同实现」？徽标在主题层、守卫拷贝全在站点层，收敛会引入跨层调用。
3. **若选 a**：徽标与两处 `where` 的「同源」关系如何在文档上表达（docstring 互指？）；**若选 b / c**：Hugo partial 替代 `where` 的写法代价（range + append 重建 slice）是否可接受。

边界（不开票）：模块的入参形态与返回语义归 0074；落点分层归 0075；消息与命名归 0076；测试缝归 0077。

## Resolution

2026-10-25 · grilling（HITL，项目负责人四问定案；按负责人指示同场进入施工，决议先落）：

**边界（Q1）**：**谓词判「契约」、边界选 (a) 只做类型校验**。判据 = 0061 所有权测试：三处谓词「同义不同形」——post-items 无条件过滤（ADR-0009 精选链组成部分）、product-items 条件过滤（ADR-0006 入参语义）、徽标单页渲染判定（ADR-0012 主题层契约），各有其主。合并 = 为三种真实差异参数化，正是 0061 对 BAD_CASE_EXPECT 枪毙的「搬家加参数化，不是集中」。`where`/`eq` 对 bool 匹配语义正确（0072 实证）且零成本；partial 循环重建 slice 是反惯用法 + 构建期开销。守卫四件套（`isset` + `%T` + `ne "bool"` + errorf）是唯一逐字同构的机制，收敛它即兑现目的地。

**文档架构（Q2）**：**双向互指**——模块 docstring = featured 类型执行契约的唯一定义处（只认 bool true / 未声明合法 / 非 bool 即 errorf + 消费面清单 + 徽标「语义共享、实现独立」声明）；badge 与 post-items / product-items 各留一句指针。这是 ADR-0012「谓词同源、契约各自独立」的落地形态，也是「AI 可导航」的落点。

**边界文本（Q3）**：**校验器，不是选择器/取数器**——不拥有数据获取、选择语义（where/eq）、渲染呈现、消息前缀措辞（前缀归 0076；模块承担 errorf 骨架 + origin 注入点）；遍历归属（值级/条目级/批级）归 0074，本票不预设。docstring 边界文本一句话：只回答「这个 featured 值合法吗」。

**测试口径（Q4）**：**零增减、零改写**——三条现有坏值断言（文章 string/int + 产品 string）原样存活，它们锚消费链「构建失败 + 消息子串」行为而非实现；模块不新增专属断言（直接探针归 0077 裁）；SOP 缺口留 0077。验收 = 三套全绿 + 断言计数持平 + **变异等价**（破坏共享模块 → 三条断言同时红）。若 0076 改消息前缀，期望子串同步改——改写锚点不是删断言。

**对下游的连锁后果**：
- **0075 张力消解**：徽标不消费模块 → 三消费方全在站点层，ADR-0008 判据只剩「站点层」一个答案，该票降级为确认票。
- **雾区「谓词合一后的构建期开销」负向了结**（不合并，开销面不存在）。
- **0074 收窄**：模块只校验不返回过滤结果；「值 / 条目 / 整批」仍开放。
- **0076（消息形态与命名）/ 0077（测试缝）原样保留**。

**施工指针**：按本票决议 + 施工期取舍（0074/0075/0076 待复核，取舍记录在 commit message）落 `layouts/partials/featured-guard.html` + 三处调用改写 + 四处 docstring 指针；红绿 = 现有断言为 oracle，逐切片变异证「切片确经模块」；SOP 侧无断言（0077 缺口）以临时坏值 fixture 手工验证。
