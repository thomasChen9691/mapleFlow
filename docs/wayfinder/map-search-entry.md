# 搜索入口图（候选 12）

## Destination

把站内搜索的入口与结果呈现，从现状（菜单项进 search 页 + 页内 Alt+/ 唤起 + 结果只渲染标题与链接）深化为决策完备、可测试、AI 可导航的模块：入口形态定案、呈现层加深与否、契约定义处与测试缝落位——达到「可施工状态」即收口。从现状深化，不替换搜索实现；本图只产决策，施工经项目负责人指示后展开。

## Notes

- **边界（开图时与项目负责人钉死，2026-10-23）**：本图 = `docs/backlog.md` 第 12 项「搜索入口形态」+ 交接文档指出的第二个子问题「渲染层要不要加摘要/标签」；第 11 项已决「不重写引擎」（ADR-0010 2026-10-23 指针）——本图一切方案以不重写为前提，「第二个消费方」触发条件的重评归 0050 / 0052；第 13 项（精选三条雾区）不属本图；不替换搜索实现；不动视觉 / CSS 调值；不随图做内容填充（buy_url/listed、about.md、socialIcons）。
- **工单纪律（项目负责人开图时明确）**：每张工单是待决策问题、不是施工任务；一次会话最多解决一张（research 除外）；地图是索引不是仓库，决策只存在于工单。
- 闭卷 ADR：0002（no-js 渐进增强基线）、0006、0007（reveal 协议——新入口交互的归属问题）、0008（主题 fork 分层判据：两层不得有同相对路径文件）、0009、0010（搜索契约——六字段冻结、fastsearch 现状快照契约为本图输入、「不重写」结论与两个重评触发条件、改投影字段三处同步纪律）。
- 已决输入：ADR-0010 指针（2026-10-23）——不重写 fastsearch；若「结果可读性」成为真实需求，只改渲染层（摘要 / 标签），不动引擎；「引擎 ESM 化 + 容错 UX」长期挂起，触发条件 = 真被 XHR 静默失败咬到、或出现第二个消费方。**本图大概率就是该触发条件的审视场：任何全站 / 首页入口都让 fastsearch 多一个加载页面。**
- 术语以根目录 `CONTEXT.md` 为准；本图可能新增「搜索入口」类术语条（措辞归 0054，排图期不预设用词）。
- Hugo 0.164 语义编写（CI 钉版）：0.166+ 条件多 return 写法本地过、CI 红，禁止。
- 测试总原则：Hugo 无模板单测，静态产物只能 build-then-assert；fixture 基建单份（现有三套构建：dataDir fixture / contentDir fixture / 真实数据）；行为断言先例 = `npm test`（jsdom，`assert_reveal.mjs`，样本手写镜像 DOM 契约、不用构建产物）；变异检验 + 独立字面量期望值。
- 用户是项目负责人：HITL 工单必须实时对话解决，agent 不得自答；事实自己查，决策问用户；一次一问，先给推荐答案。
- 事实底座：`research/0049`（排图日由研究子代理落盘）。后续工单的事实争辩以该份为准，不重新推导。

## Decisions so far

<!-- 索引：每个已决工单一行 gist + 链接；决策详情只存在于工单，此处不重述。 -->

- [搜索入口现状事实底座（盘点）](tickets/0049-search-entry-facts.md) — fastsearch 现仅 search 页加载且**现状文件不可原样搬全站**（无 `#searchInput` 页面抛 TypeError）；「Alt + /」实为 header.html 的 accesskey 属性（fastsearch 侧零参与零测试）；search 页 focus 靠原生 autofocus；首页无搜索区块；结果 li 只渲染标题+链接、摘要/标签均在投影内（加深渲染不触发三处同步）；行为测试为零。缺口 9 条：入口无契约定义处 / 加载条件无守门 / 「第二个消费方」无观测面等。
- [入口形态定案](tickets/0050-entry-form-decision.md) — **P1（任意页 1 步发起搜索）× A 单独（全站快捷键）× 轻形态（跳转 search 页+聚焦，重浮层否决）× 键位 `/`（焦点/修饰键门控）**；seam = 站点层新文件 `assets/js/mf-search-entry.js` 经 extend_footer 双 js.Build 全站恒加载；URL 走 js.Build params 全局注入（`typeof` 守卫、缺失静默降级）；**重评结论：不构成第二个消费方、不触发 ADR-0010 重评**；测试 = jsdom 新建 assert_search.mjs 四行为 + 产物四断言；fastsearch/index.json/search 页/首页零改动。施工经项目负责人指示展开中。frontier = 0051。
